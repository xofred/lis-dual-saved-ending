# 開學日

九月的第一個週一早晨，波特蘭社區學院（PCC）喀斯喀特校區的林蔭道上，上演了一場引來全校注目的「硬核家長親友團大護航」。

一輛經過 Chloe 親手爆改、漆著啞光炭黑與藍色火焰拉花的經典雪佛蘭舊皮卡，帶著低沉渾厚的排氣聲浪，穩穩停在了藝術與應用技術學院大樓正門口。

皮卡後斗裡整整齊齊碼放著 Miles 的重型畫筒、黑胡桃木工具箱，以及那台由工坊全員合力組裝的便攜式精密金屬雕刻台。

**一、 氣場拉滿的送行親友團**

車門一開，這支出現在校園裡的隊伍瞬間讓周圍拖著行李箱的新生們自覺讓開了一條通路：

- **全副武裝的「汽修家長」Chloe：** 戴著深色墨鏡，反扣著棒球帽，嘴裡咬著棒棒糖，單手把 Miles 那個裝滿工具、少說有八公斤重的帆布工具袋輕鬆拎下車斗，大聲嚷嚷：「小子，要是系裡哪個自以為是的教授敢挑剔你車削的游標卡尺精度，立刻打電話給老娘，老娘開著推土機來給他的辦公室重新做動態平衡！」
- **全方位抓拍的「隨行攝影師」Max：** 脖子上掛著兩台相機——一台裝著黑白底片的大畫幅旁軸，另一台是拍立得。Max 從下車開始就沒停下按快門的指尖，一邊後退一邊抓拍 Miles 整理雙肩包的瞬間，黑框眼鏡後滿是驕傲：「Miles！看鏡頭！對，把入學通知書拿在胸前，這個晨光打在側臉上的角度太棒了！」
- **名媛的「降維資源鋪路」Victoria：** 穿著一襲剪裁銳利的深藍色西裝，踩著高跟鞋，拿著手機在一旁與藝術系主任通話：「……是的，布朗教授，他的作品集原件在二號車廂展廳有備份。另外，基金會設立的專項材料實驗室基金已經到賬，我不希望看到他的工位缺少任何一台五軸聯動雕刻機。」
- **大天使的「愛心補給站」Kate：** 溫柔地走上前，替有些窘迫的 Miles 整理好新外套的衣領，遞上一個沉甸甸的保溫提籃：「裡面有剛烤好的迷迭香牛肉三明治、藍莓鬆餅和兩大瓶蜂蜜檸檬茶。要是下午畫室冷，記得喝一點暖暖身子哦。」

**二、 隱秘守護者的校園注視**

Miles 被四位姐姐圍在中間，臉頰微紅卻挺直了脊樑，眼底滿是前所未有的踏實與光芒。

當他接過工具箱、轉身走向教學大樓的階梯時，腳步忽然一頓，下意識地望向校門口對街的那排老楓樹。

樹蔭下，一輛洗得一塵不染的黑色雪佛蘭轎車靜靜停在街角。車窗半降，Robert McCall 穿著那件標誌性的深色夾克，手裡捧著一本平裝小說，目光穿過斑駁的樹影，沉靜而深邃地落在 Miles 身上。

隔著一條街道，兩人目光交匯。

Robert 微微收起書頁，朝著 Miles 緩緩點了點頭，眼神裡沒有多餘的言語，只有歷經風雨後對一個年輕人走向新生的最高認可。Miles 深吸一口氣，朝著對街的長者深深鞠了一躬。

**三、 新起點的定格**

「走吧，大學生！」Chloe 拍了拍皮卡的引擎蓋，吹了個響亮的口哨，「去把你的名字刻進那些象牙塔的獎狀裡！」

Max 在最後一刻迅速按下快門。

**「咔嚓。」**

照片裡，背著雙肩包的 Miles 站在充滿古典氣息的學院大門前，陽光灑在他年輕乾淨的臉龐上；背後是靠在改裝皮卡旁笑得肆意的 Chloe、正優雅掛斷電話的 Victoria、溫柔招手的 Kate，以及校門外如磐石般守望著的黑色轎車。

引擎再次轟鳴，皮卡載著滿滿的笑聲駛回東區鐵道花園。

而在這所大學的畫室與車間裡，一個曾經在街頭泥潭中掙扎的少年，正握緊手中的刻刀與畫筆，正式翻開了屬於他自己的燦爛人生篇章。
