📓 Max 的手帳

深夜一點，樓下的喧鬧終於歸於平靜。

二樓臥室的書桌前，那盞暖黃色的小檯燈孤零零地亮著。Max 盤腿坐在旋轉椅上，手裡捏著一支 0.38 毫米的黑色極細勾線筆，咬著筆帽，對著攤開的手帳本笑得雙肩發顫。

身後的大床上，Chloe 已經四仰八叉地睡熟了，身上蓋著印有老式皮卡圖案的薄被，嘴裡還帶著一絲薄荷糖與櫻桃汽水的甜味，發出均勻微沉的呼吸聲。

Max 轉過身，深吸一口氣，將筆尖輕輕落在空白的牛皮紙頁上。

案發現場圖解（Maxine 的精準還原速寫）

左側：受難的西雅圖名媛

Max 用幾筆凌厲的線條勾勒出一個頂著精緻波浪捲、身上裹著華麗浴袍的火柴人 Victoria。

火柴人的腦門上頂著三團巨大的黑色旋渦狀「怒火符號」，臉頰兩側塗著兩團誇張的斜線腮紅，眼角飈出兩道瀑布般的眼淚。

她的手腕和小腿上被 Max 用紅筆畫了幾個巨大的圓圈，並用箭頭拉出一行小字標註：「致命生化打擊：俄勒岡特種吸血蚊群」。

頭頂的咆哮對白框裡寫著狂暴的字體：「把妳在中世紀修道院學的那套黑魔法收起來！！！」

中間：無辜的大天使 Kate

旁邊是一個頭頂頂著小光環、繫著碎花圍裙的 Q 版 Kate。

雙手捧著一罐冒著仙氣的綠色小瓶子（標註：「長老認證草本精華」），一臉無辜地眨著兩隻純潔的大眼睛。

身後飄著一行聖經體文字泡泡：「主啊，可是她剛才真的很舒服，還發出了長長的嘆息……」

右側：笑到靈魂出竅的藍毛暴徒

旋轉樓梯上畫著一個手腳扭曲成「大」字形、順著扶手一路滑落的藍髮火柴人 Chloe。

嘴巴被畫得比臉還大，眼角笑飛出兩顆大淚珠，手裡的汽水罐正在空中做拋物線運動（汁水四濺）。

對白框用標誌性的粗獷字體狂草著：「深度揉捏！靈魂洗禮！老娘要給這齣劇買斷波特蘭巡演版權！」

樓梯拐角角落：慘遭波及的 Max 本人

一個戴著大黑框眼鏡的縮小版火柴人，正對著天花板狂噴出一條橫貫半個頁面的果汁水柱（標註：「無辜受害者 / 果汁水槍發射器」）。

畫完這組生動的四格簡筆畫，Max 換上了一支深藍色的墨水鋼筆，在畫面的最下方工工整整地寫下了今晚的「案件備忘錄」：

【案件代號：波特蘭客廳草本推拿大案】

時間：週二深夜 00:23

案發地點：珍珠區 Loft 一樓真皮沙發

核心罪證：一罐純天然洋甘菊薄荷膏、四個蚊子包、半杯噴在扶手上的葡萄汁。

結案陳詞：

千萬不要讓 Kate 在緊張的時候用語音描述人體護理過程。

Chloe 的笑點比老皮卡的底盤還要低。

明早起床前，必須確保 Victoria 喝到第一杯手沖咖啡，否則整間屋子可能會迎來名媛的毀滅性法務傳票。

寫完最後一個字，Max 忍不住再次笑出了聲。

她輕輕吹乾頁面上的墨跡，從抽屜裡摸出一枚小小的綠色薄荷葉貼紙，端端正正地貼在了 Kate 的小光環旁邊。

窗外，波特蘭初夏的夜風輕輕吹動著天台的門簾，帶來遠處街道隱約的汽笛聲與植物的泥土清香。Max 合上手帳本，將筆放回筆筒，輕手輕腳地爬上床，鑽進了散發著熟悉的機油與柑橘香氣的被窩裡。
