雙保結局

如果那年風暴之後，小鎮與 Chloe 都活了下來

官方原作把玩家推向一道殘酷的電車難題——犧牲小鎮，或是犧牲 Chloe， 二選一，沒有第三條路。這部合集是對那道難題的另一種回答：

如果 somehow，兩者都保住了呢？

這裡收錄了115章，從風暴退去的第一個清晨，到公路盡頭的星空， 記錄著 Chloe 與 Max，還有這座小鎮上每一個劫後餘生的人， 如何在一個「不該存在」的結局裡，笨拙卻真實地活下去。
